# ABDUH DEALS: product hub (free Linktree alternative)

A mobile-first Arabic (RTL) product page for a TikTok bio. Products come from a Google Sheet, so there's no code to edit after setup.

- Search by **product number** from the video (Arabic digits supported) or by name
- Direct product links: `/?p=12`
- Category, store (Amazon / AliExpress), featured, new and big-discount filters
- Discount % badges, "new" badges, share buttons, Telegram banner
- Optional free click statistics (GoatCounter)
- Fast in TikTok's in-app browser: no frameworks, caches the product list
